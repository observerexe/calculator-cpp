# Calculator

Консольний калькулятор на C++20. Робота в процесі: зараз готовий лише токенізатор.

## Що вже є

Програма читає вираз зі стандартного вводу й розбиває його на токени: числа (цілі та дробові) і оператори.

```
$ echo "12+3.5*2" | ./build/debug/Calculator
12 + 3.5 * 2
```

## Що далі

- обробка пробілів і некоректного вводу
- розбір виразу з урахуванням пріоритету операторів і дужок
- обчислення результату

## Збірка

Потрібні CMake 3.21+, Ninja і clang++.

```sh
cmake --preset debug
cmake --build --preset debug
./build/debug/Calculator
```

Для оптимізованої збірки використовуй пресет `release`.
